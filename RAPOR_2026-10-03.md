## 1. Bu oturumun en önemli bulgusu: cihazda bulunan kritik hata (kök neden düzeltildi)

### 1.1 Semptom (gerçek cihazda, ekran görüntüsü ile kanıtlandı)
Varlık detayında bir **zaman dilimi chip'ine** (örn. "1 sa") basıldığında ekranın
grafik alanı Riverpod'un kırmızı hata widget'ı ile değişti:

> `Tried to modify a provider while the widget tree was building.`

### 1.2 Kök neden
`lib/features/asset_detail/asset_detail_screen.dart` → `_ChartSectionState.didUpdateWidget`:

```dart
if (old.interval != widget.interval) {
  ...
  ref.read(crosshairCandleProvider(widget.assetId).notifier).pick(null); // ❌
}
```

Widget yaşam döngüsü (`didUpdateWidget`) **build aşamasıdır**; Riverpod bu aşamada
provider değişimine izin vermez. Provider yazımı, dilimin değiştiği **tek olay
bağlamına** (`_IntervalBar.onChanged`, kullanıcı tiklaması) taşındı; `didUpdateWidget`
artık yalnızca yerel durumu (`_interaction`, `_lastCandles`) sıfırlar.

## 2. Bu oturumda düzenlenen diğer hatalar (kısa özet)

Hepsi `dart analyze` (exit 0) ve **294 test** ile doğrulandı:

1. **Alarm watchdog** — ön/arka plan farkındalığı (`appInForegroundProvider` dinlenir,
   ön plana dönünce anında değerlendirme); `_seenNews` kalıcı hale getirildi
   (`AlertStore`, en fazla 200 kayıt).
2. **Alarm ekranında çift `%`** — `TrFormat.percent(..., withSign: false)`.
3. **Sayı ayrıştırma** — `TrFormat.parse` eklendi: `"1.5"` artık 15,5 değil **1,5**
   (Türkçe ondalık); `alert_sheet` ve `transaction_sheet` bağlandı. `TrFormat.money`
   ondalık basamak önbelleği düzeltildi. (+12 test)
4. **Charset çözümleme** (`ApiClient`) — UTF-8 BOM → sıkı UTF-8 → beyan eden charset
   (ISO-8859-9/windows-1254 dahil) → latin1 yedeği; asla fırlatmaz. RSS `pubDate`
   ofseti (GMT/UT dahil) çözümlenip yerel zamana çevriliyor. (+3 test)
5. **Haber yenileme önbelleği** — `NewsRepository.invalidateCache()`; çekmeştiri/
   kategori yenilemesi gerçekten yeniden çeker.
6. **TCMB `%` cache** — hatalı günler cache'lenmiyor (yalnız başarılı çekimler).
7. **Portföy gün değişimi** — ÷0/NaN koruması (+test).
8. **Piyasalar arama** — tüm `AssetCatalog` üzerinde, Türkçe-duyarsız normalizasyon
   ile (cihazda "usd" → XAUUSD, XAGUSD, USD doğrulandı).
9. **Android geri tuşu** — `PopScope`: tam ekran/cizim aracını önce kapatır,
   normalde detay → ana sayfa akışı korunur (cihazda doğrulandı).
10. **Kart kimlik satırı** — taşma yerine güvenli kırpma (`Flexible` + ellipsis);
    cihazda taşma yok.

## 4. Release APK — iki sorun, ikisi de kökten çözüldü

### 4.1 ASCII yol zorunluluğu (kalıcı bilgi)
`flutter build apk --release` proje yolundaki **`ü` (Masaüstü)** yüzünden başarısız oluyor:

```
Error: Unable to read file: ...\Masaust...\app.dill
Dart snapshot generator failed with exit code 255
```

AOT `gen_snapshot` Windows'ta bozuk kod sayfası ile yol alıyor. **Debug** build bunu
etkilemez (JIT); bu yüzden debug her yerde çalışır.
**Çözüm (geçici):** release, ASCII ayna dizin `C:\goldproj`'dan üretildi
(kaynaklar `lib/`, `test/`, `android/`, pubspec bu oturumda senkronize edildi).
**Öneri (kalıcı):** projeyi ASCII bir yola taşın (örn. `C:\goldproj`).

### 4.2 Eski build artıkları → eksik `flutter_assets` (release'e özel)
İlk release denemesi APK'sında **hiç** `flutter_assets` yoktu (font/shader/
AssetManifest sıfır). Cihazda bu, `Asset 'shaders/stretch_effect.frag' not found`
yakalansız istisnasına yol açtı (bu shader Flutter framework'ün kendi dosyasıdır).
**Çözüm:** `C:\goldproj` içinde `flutter clean` + temiz rebuild.
**Doğrulama (aapt):** `assets/flutter_assets/AssetManifest.bin`,
`shaders/ink_sparkle.frag`, `shaders/stretch_effect.frag`,
`fonts/MaterialIcons-Regular.otf` → kurulum → cihazda **hata logu yok**, ekranlar tam.

### 4.3 Üretilenler
| Dosya | Boyut | Not |
|---|---|---|
| `build\app\outputs\flutter-apk\app-debug.apk` | 181.094.939 B | Cihaza kuruldu ve test edildi |

Release, cihazda şunlarla doğrulandı: açılış/Ana Sayfa, varlık detay grafik
